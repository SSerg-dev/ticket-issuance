# Pickens Issues — оформление билетов

Тестовое решение интерфейса покупки билетов на мероприятие. Реализованы полный пользовательский сценарий, проверка сопровождения ребёнка взрослым, редактирование заказа, расчёт стоимости, успешный результат и демо-сценарий отсутствия мест.

## Стек

- Native HTML + TypeScript + Vite
- Tailwind CSS 4
- Lucide Icons
- Без фреймворков и UI-kit: небольшой state machine и нативный DOM

## Запуск

```bash
npm install
npm run dev
```

Сборка для production:

```bash
npm run build
npm run preview
```

## Проверка сценариев

1. Заполните участников (до 4 человек).
2. Для детского билета младше 14 лет добавьте участника от 18 лет.
3. Укажите email и перейдите к проверке заказа.
4. Оставьте демо-переключатель выключенным для успешного оформления.
5. Включите «Имитировать отсутствие мест», чтобы увидеть обязательный sold-out результат и вернуться к редактированию.

## Статус

- Фактические затраты: около 2 часов, включая изучение задания, смену архитектуры, реализацию и проверку.
- Незавершённые пункты: видеозапись не входит в репозиторий; платёж и серверная бронь заменены моковым сценарием согласно заданию.
